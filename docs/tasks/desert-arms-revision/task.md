# Arms: hands held with intent, an LCD gauge, quieter stitching
Type: feature
Status: complete
Cycle: 1

## Goal
Revise the desert player's arms (`desert/tools/blender/build_arms.py`, `desert/assets/characters/arms.glb`) in three ways. Everything else about them stays as it is.
- **Hands.** Both hands droop palm-down at the wrist and read as limp. Roll each hand about its own pointing direction so the palms face each other with the thumbs on top, as if loosely gripping.
- **Gauge.** The left bracer's gauge shows three cyan bars. Replace them with an LCD screen: a backlit dark green-grey panel showing `47%` and a block cursor in a green, blocky terminal font.
- **Stitching.** The glove and strap stitching is a pale tan. Make it a darker brown that sits closer to the leather.

The right-wrist sun compass doesn't move. The walk clips are regenerated from the new rest pose with the same motion.

## Decisions
All from the planning interview with the user, 2026-10-30.
- **The turn is a roll** (Q1, Q9): each hand rolls about its pointing direction until the palms face each other and the thumbs are on top. That is `HAND_ROLL` 90° (now 24°). The hand's pointing direction (`HAND_YAW`, `HAND_PITCH`, both 16°) stays the same.
- **What moves** (Q2): only the hand and what it carries. That is the palm, every finger and thumb segment, and the stitches, knuckle pads and patches on them. Each finger keeps its curl relative to the hand. The rest is kept, with every vertex within 1e-6 m of the shipped glb's rest pose. That covers the shoulders, upper arms, forearms, wraps and tails, the cuffs with their stitches, straps and rivets, the bracer and all its devices, the gauge's bezel, and the compass. So does every joint's position up to the wrist.
- **Hand-placement checks** (Q3): the index knuckle range `KNUCKLE_Y` widens from (-0.70, -0.50) to (-0.70, -0.40). `HAND_X` and every rule in `desert/docs/art-style.md` stay, including nothing above NDC y -0.30 at every sampled clip frame.
- **Compass fallback** (Q4, Q10): the compass face must stay wholly seen from the eye (the existing check). If the rolled right hand hides any of it, lower `HAND_ROLL` on both hands in 5° steps (85, 80, 75) to the first value where it's seen. Below 75° the task stops as blocked. The planning trial at 90° hid none of it.
- **The readout** (Q5, Q11): the window keeps its size, bezel, screws and 3 mm recess. A panel fills the window floor. On it, `47%` and a solid block cursor, one row, centred, in a 3×5 blocky font. Each lit dot is a 2.4 mm square emissive box standing 1.0 mm off the panel. Neighbouring dots touch, so strokes read as solid lines. One blank column separates the glyphs. Glyphs are binding (Assets).
- **Screen materials** (Q6):
  - `Arms_Glow` (slot 4, emissive) is recoloured to phosphor green, sRGB (70, 255, 110), and becomes the readout's dots.
  - A new emissive material `Arms_Screen`, sRGB (30, 46, 36), is appended as slot 14 for the panel. It's emissive so it reads as backlit and looks the same by day and night.
  - The arms take actor slots 0–14, and a new desert character starts at 15.
- **Stitch colour** (Q7): `Arms_Thread` goes from (196, 170, 124) to sRGB (132, 100, 70). On the bracer straps (`Arms_Strap` (118, 84, 56)) the stitching becomes subtle. The user accepted that.
- **Clips** (Q8): `Arms_Walk` and `Arms_Sprint` keep every number in `CLIPS` and `CLIP_TARGETS` and their hinges. They are regenerated by the build from the new rest pose. The sprint's fist still curls each finger 25° toward its palm, which now faces inward.
- **The pose as rendered** (Q12): the user approved the planning trial's eye view: `HAND_ROLL` 90°, everything else as shipped. The trial's measurements are under Assets, "Expected values".

## Layering
- Engine: none. Emissive actor materials (`ActorMaterial::glow`, from `emissiveFactor`) and 64 actor slots already cover a 15th material.
- Game (`desert/`): `desert::Arms` already copies every glb material into its slots. Only the slot comment in `arms.hpp` and the material constants in `arms.cpp` gain `Arms_Screen`.
- Assets: `build_arms.py` rebuilds `arms.glb` and its previews.
- Orthographic mode: untouched.

Remove `BAR`, `BAR_GAP` and `BAR_MIN_PX`. Add after the gauge's constants (binding):
```python
# The gauge's screen: a backlit panel on the window floor (across, up the
# forearm, and how far it stands off the floor, sunk as far into it), and a
# readout of lit dots on it in a 3x5 font: square dots this wide, standing
# LCD_PROUD off the panel (sunk 0.4 mm into it). One blank column between
# glyphs. Each glyph is five rows, top first, X lit.
LCD_PANEL = (0.044, 0.021, 0.0006)
LCD_DOT = 0.0024
LCD_PROUD = 0.0010
LCD_TEXT = (
    ("X.X", "X.X", "XXX", "..X", "..X"),   # 4
    ("XXX", "..X", "..X", ".X.", ".X."),   # 7
    ("X.X", "..X", ".X.", "X..", "X.X"),   # %
    ("XXX", "XXX", "XXX", "XXX", "XXX"),   # the block cursor
)
LCD_MIN_PX = 3.0             # each dot at least this wide on screen, both ways
```

**`Builder.gauge()`**: replace the bars' loop with the screen (sketch):
```python
        floor = top - n * RECESS
        pw, pu, pt = LCD_PANEL
        q = self.piece("L.screen", "Arms_Screen")
        la, lb = self.box_loops(floor - n * pt, floor + n * pt, n, u, pw, pu)   # pw along w, pu along u, as the bars were
        self.loft(q, [la, lb])
        self.gadget(q, "L")
        self.attach.append(("L.screen", "L.gauge"))
        # Reading directions on screen: `right` the one of +-w whose end
        # projects further right (NDC x), `up` the one of +-u that projects higher.
        right = w if project(floor + w * 0.01)[0] > project(floor)[0] else -w
        up = u if project(floor + u * 0.01)[1] > project(floor)[1] else -u
        face = floor + n * pt
        cols = 4 * len(LCD_TEXT) - 1
        for g, rows in enumerate(LCD_TEXT):
            for r, row in enumerate(rows):
                for c, lit in enumerate(row):
                    if lit != "X":
                        continue
                    centre = face + right * ((4 * g + c - (cols - 1) / 2) * LCD_DOT) + up * ((2 - r) * LCD_DOT)
                    name = f"L.lcd.{g + 1}.{r + 1}{c + 1}"
                    q = self.piece(name, "Arms_Glow")
                    la, lb = self.box_loops(centre - n * 0.0004, centre + n * LCD_PROUD, n, up, LCD_DOT, LCD_DOT)
                    self.loft(q, [la, lb])
                    self.gadget(q, "L")
                    self.attach.append((name, "L.screen"))
                    self.lcd.append((name, g, r, centre + n * LCD_PROUD, right, up, n))
```
`self.bars` in `Builder.__init__` becomes `self.lcd = []`. Update the docstring: "...recessed 3 mm, with a backlit screen reading 47% and a block cursor."

**`framing()`**: replace the "Gauge bars" block with the readout's checks (binding), using the same tree and `poly_piece`:
- every vertex of every `L.lcd.*` piece and of `L.screen` is `in_view`;
- each dot's top centre: the ray from the eye toward it first hits that dot (as the bars' `bar_seen`);
- each dot's width on screen is at least `LCD_MIN_PX`, both from `top ± right·LCD_DOT/2` and from `top ± up·LCD_DOT/2` (projected, in pixels, as the bars' `px`);
- the panel faces the eye: `n · (-top).normalized() ≥ FACE_COS` for every dot's top centre;
- reading order: the mean NDC x of each glyph's dots strictly increases from glyph 1 to glyph 4, and within each glyph the dots of row 1 project higher (NDC y) than those of row 5.

Print, in place of `gauge_bars_ndc` and the per-bar values, `m["lcd"] = {"dots": <count>, "ndc": {"x": [min, max], "y": [min, max]}, "px_min": [across, up], "facing_min": <cos>}`.

**`check_glb()`**: docstring "the 15 materials in order with their colours, only the glow, amber and screen emissive". The code already loops over `MATERIALS`.

**`main()`**: read `before` from `OUT` after `export()` and before `add_clips(OUT, b)`. So `check_glb_clips` compares the glb with clips against the glb they were added to. It no longer compares against the previous file, whose rest pose this task changes on purpose. Remove the `PXE_ARMS_BEFORE` loop, its docstring lines (lines 9-10), and `DEFAULT_GLB` if nothing else uses it. The kept-pieces script (Verification 3) does this task's comparison with the shipped glb.

**Module docstring**: say the palms face each other with the thumbs up (line 30: "palms turned inward and down"). Replace the gauge's `Arms_Glow` line with `Arms_Screen` (a backlit panel on the window floor) and `Arms_Glow` (the readout: 47% and a block cursor in lit 2.4 mm dots). Line 109 becomes "slots 0-14".

Rebuild headless (`--python-exit-code 1`). Keep the new previews: the asset changed.
