# Tools
Scripts for building, running and checking pxe, and for running the agent workflow. Check here before writing a script or a long command sequence by hand. If nothing fits, write it in the task's `scripts/` folder and record it in the task's `friction.md`: once the same job has been done by hand three times, the retro turns it into a tool here.

| Tool | What it does |
| :- | :- |
| `tools/build.sh [debug\|release] [game\|desert\|example] [-- args]` | Configures if needed, builds the engine, both games and the example with the CMake presets, and optionally runs one of them. `--help` for details. |
| `tools/ortho-check.sh <base-ref>` | Compares the orthographic mode's standard cases (the game's captures and self-test, the example's `--capture`) byte for byte between a base commit and the working tree. Builds the base once per commit in `${TMPDIR:-/tmp}/pxe-render-check/<sha>/` and prints that directory, so the base's binaries can be run directly afterwards (for example `<dir>/build/release/game/pxe --bench 600` to compare frame times); outputs go to `${TMPDIR:-/tmp}/pxe-render-check-run.XXXXXX`. Exit 0 all identical, 1 any differs, 2 bad usage. `--help` lists the cases. |
| `tools/perspective-check.sh <base-ref>` | The same for the perspective mode's standard cases (the desert's `--capture` and `--hour 21 --capture`, the example's `--first-person --capture`), with the same base build and output directories. The base's binaries can be run by hand afterwards, from `${TMPDIR:-/tmp}/pxe-render-check/<full sha>/build/release/` (`desert/pxe_desert`, `examples/minimal/pxe_minimal`), and the base's own captures of the standard cases stay in the printed run directory's `base/`. |
| `tools/glb.py info <file.glb>` / `tools/glb.py compare <a.glb> <b.glb> [--tolerance T]` | Reads glb files, standard library only, so it runs under `python3` and inside Blender. `info` lists the materials, meshes and triangle counts, skins and joints, and each animation's duration, channels, key counts and interpolation. `compare` checks two glbs' materials, joints, joint transforms, inverse bind matrices and rest mesh (positions and indices), and lists their animations without comparing them: exit 0 identical or within the tolerance, 1 differs, 2 bad usage. As a module (`sys.path.insert(0, "<repo>/tools"); import glb`): `glb.read`, `glb.accessor`, `glb.node_trs`. |
| `tools/backlog-loop.sh [--max-batches n] [--budget usd]` | Runs `/backlog-run` in a loop, one fresh headless Claude session per batch, until the backlog has nothing left to run. Logs go to `.backlog-runs/`. `--help` for details. |
| `tools/blender/build_<asset>.py` | Rebuilds each asset in Blender. Written and run by the designer. |
